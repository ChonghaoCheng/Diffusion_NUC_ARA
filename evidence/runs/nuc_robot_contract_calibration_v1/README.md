# NUC robot contract calibration v1

Code commit: `84b3e9892d3a2736b070852b8d1680019c919174`  
Branch: `exp/nuc-robot-coupling-v1`

This pre-method calibration freezes temporal NUC evaluation resolution, q-space interpolation density, normalized 5D singularity admission, and NUC equivalence tolerance. It does not compare skeleton-selection methods. The collision check is limited to contacts represented by the loaded standalone UR5e Menagerie model.
